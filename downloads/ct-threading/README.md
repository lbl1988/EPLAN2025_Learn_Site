# 2025 CT 机械式穿线 示例工程

## 项目概述

本示例为 EPLAN 2025 新功能演示工程，展示电流互感器 (CT) 穿芯走线的"机械式穿线"连接定义点类型。

## 功能说明

### 什么是机械式穿线？

在 EPLAN 2025 中，新增了一种连接定义点类型——"机械式穿线"。当电流互感器 (CT) 的二次侧导线需要穿过 CT 的穿芯孔时，使用此连接定义点可以：

1. 在原理图中显式表示穿线关系（而不仅仅是电气连接）
2. 连接清单和布线列表中同步反映穿线依赖
3. 计算实际布线长度时自动计入穿线路径

### 关键操作步骤

1. 在原理图中放置 CT 符号
2. 在 CT 穿芯孔位置插入"机械式穿线"连接定义点
3. 设置穿线方向和穿芯次数
4. 生成连接清单报表验证
