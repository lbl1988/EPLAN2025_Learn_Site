1

EPLAN 平台与 Electric P8 概念

ECAD vs CAD 的本质区别、EPLAN 平台模块总览（Electric P8 / Preplanning / Pro Panel / Harness proD / Cable proD / EEC）。

核心概念

EPLAN 是"工程级 ECAD"平台，不是"画图软件"。与 AutoCAD 的本质区别：EPLAN 以对象为中心——每个符号、连接、设备都是有属性的智能对象，而非离散的线条。画完原理图后，端子排、BOM、电缆清单全部自动生成，这是 CAD 做不到的。

EPLAN 平台包含六大模块：Electric P8（原理图设计）、Pro Panel（3D 机柜布局）、Cable proD（3D 虚拟布线，2025 新品）、Harness proD（线束设计）、Preplanning（前期规划）、EEC（工程配置）。初学者只需关注 Electric P8，其余模块在精通篇涉及。

关键操作步骤

  1. 安装 EPLAN Electric P8 2025（需 Windows 10/11 64 位）
  2. 首次启动选择许可证类型（试用 30 天 / 正式授权）
  3. 认识启动界面：项目目录、最近项目、新建项目向导
  4. 理解 EPLAN 数据库：所有对象存储在 SQL 数据库中，不是文件
常见错误：把 EPLAN 当 AutoCAD 用——直接画线而不插入符号。这会导致后续所有报表（BOM、端子排、电缆）全部无法自动生成。正确方式：始终通过"插入符号"放置元器件。

2

项目结构：项目 / 页 / 页类型 / 图框 / 层

项目驱动的组织方式，页类型（多线原理图 / 总览 / 端子排图表 / 电缆图表 / 部件清单），图框与层的概念与作用。

核心概念

EPLAN 以项目为最顶层容器。一个项目 = 一台设备/一个工程的全部电气数据。项目内按页组织，每页有类型：

  • 多线原理图页：主电路+控制电路绘制（最常用）
  • 总览页：系统级框图、电源拓扑
  • 端子排图表页：自动生成端子排图
  • 电缆图表页：自动生成电缆连接表
  • 部件清单页：自动生成 BOM

图框是页的边框模板，含标题栏（项目名、图号、日期、版本）。层用于分组元素（如不同电压等级用不同层），可单独显示/隐藏/锁定。

关键操作步骤

  1. 文件 → 新建 → 选择模板（国内项目选 GB）
  2. 设置项目属性：项目名、客户、创建日期
  3. 新建页：页类型 = 多线原理图，图框 = GB_A3
  4. 配置层：建议预设"主电路层""控制电路层""信号层"
  5. 设置页编号规则：=高层代号 + 位置代号
提示：模板选定后中后期更改极麻烦——图框、层、符号库引用都绑在模板上。创建项目时务必确认 GB/IEC 标准。
3

界面分区与导航器

页导航器、设备导航器、端子排导航器、电缆导航器、插入中心、部件管理、属性面板。理解 EPLAN "对象 + 属性" 模型。

核心概念

EPLAN 界面的核心是导航器——不是简单的文件树，而是"数据库视图"。每个导航器从不同维度展示项目数据：

  • 页导航器：按页结构展示，最常用
  • 设备导航器：按设备层级（=高层代号+位置代号+设备标识）
  • 端子排导航器：按端子排分组，管理端子
  • 电缆导航器：电缆及芯线管理
  • 插入中心：搜索并插入符号/部件/宏

EPLAN 的"对象+属性"模型：每个元素（符号、连接、端子）都有属性面板（双击打开）。属性决定报表内容——比如部件的订货号不填，BOM 就缺数据。

关键操作步骤

  1. 打开所有导航器：视图 → 导航器 → 勾选全部
  2. 拖拽导航器面板到合适位置（建议页导航器在左、设备导航器在右）
  3. 双击任意符号 → 弹出属性对话框 → 查看可编辑属性
  4. 在插入中心搜索符号：输入关键词（如"接触器"）即可
提示：初学者最常忽略导航器。但 EPLAN 的效率恰恰来自导航器——在导航器中拖拽端子可以重排序，在设备导航器中可以批量修改属性。
4

符号库与 IEC 符号

IEC 符号标准、插入符号的多种方式（插入中心 / 路径 / 直接）、符号与功能的关系、功能定义。

核心概念

EPLAN 符号库按标准分类：IEC（国际/中国国标）、NFPA（北美）、GOST（俄语区）。国内项目用 IEC 符号库。每个符号有功能定义——比如一个方块符号可以是"接触器线圈"也可以是"继电器线圈"，功能定义决定其电气行为。

插入符号有三种方式：插入中心搜索（最推荐）、菜单路径插入、直接拖拽。符号插入后会自动获得设备标识（如 -KM1）。

关键操作步骤

  1. 插入中心 → 输入"接触器主触点" → 选择 IEC 符号
  2. 在原理图页中点击放置位置
  3. 在属性对话框中确认功能定义 = "断路器触点"
  4. 设置设备标识（DT）或使用自动编号
  5. 关联部件（选填，进阶篇详解）
常见错误：选错符号功能定义。比如把"三相交流电机"符号的功能定义设成了"直流电机"，会导致设备导航器分类错误、报表中设备类型显示异常。插入后务必检查功能定义。

5

设备标识 (DT) 与命名规则

设备标识符 (DT)、自动编号、ID 范围、命名规则配置（依据 GB/IEC 标准）。

核心概念

设备标识符 (DT) 是每个设备的唯一编号，如 -KM1、-QF2、-SB3。EPLAN 的 DT 由"标识字母+序号"组成，标识字母依据 GB/T 或 IEC 标准：K = 继电器/接触器、Q = 断路器、S = 开关/按钮、H = 信号器件。

自动编号：EPLAN 可按 ID 范围自动分配序号。比如设 KM 的 ID 范围 1-99，每插入一个接触器自动 +1。命名规则可配置编号格式（如带前缀"="高层代号）。

关键操作步骤

  1. 选项 → 设置 → 项目 → 设备标识 → 确认标识字母表（GB 标准）
  2. 设置 ID 范围：每种标识字母的起止序号
  3. 插入符号时选择"自动编号"或手动输入 DT
  4. 在设备导航器中检查编号连续性和层级
  5. 如需批量修改：右键导航器 → 重新编号
提示：GB 标准中标识字母是固定的——K 永远是接触器/继电器类，Q 永远是保护器件。不要自创标识字母，否则后续与同事协作时会混淆。
6

连接与连接定义点

自动连接、连接定义点、电位传递、连接颜色与编号、刷新连接。

核心概念

当两个符号的连接点在图上靠在一起时，EPLAN 自动建立电气连接——不需要画线。这叫"自动连接"。连接定义点用于给连接命名（如 L1、N、PE、24V+）和设置属性。

电位传递是 EPLAN 的核心概念：同名连接自动传递电位。比如标记一段导线为"L1"，所有连接到该电位的导线都自动归属 L1 相。这决定了后续报表中的连接分组。

关键操作步骤

  1. 插入两个符号（如断路器 + 接触器），让连接点对齐 → 自动连接
  2. 插入连接定义点 → 输入电位名（如 L1、N、PE）
  3. 设置连接颜色（选项 → 项目 → 连接 → 颜色编号）
  4. 刷新连接：右键页 → 更新连接（修改后必须刷新）
  5. 在连接导航器中检查所有连接是否正确分组
常见错误：修改了符号位置或连接后忘记"刷新连接"，导致连接导航器显示陈旧数据、报表中连接关系错误。每次修改原理图后务必刷新连接。
7

中断点与跨页连接

中断点的关联与排序、跨页连接的规范、T 形连接、连接导航器的使用。

核心概念

当连接需要跨越多页时，使用中断点。中断点成对出现——"源端"和"目标端"，通过相同的中断点名关联。EPLAN 自动在页边标注目标页码（如"→ 第 3 页 / 2"）。

T 形连接：三根导线的交汇点，EPLAN 自动识别为 T 节点并分配连接。跨页连接规范：主电路走第 1 页，控制电路走第 2 页，信号电路走第 3 页，通过中断点关联。

关键操作步骤

  1. 插入中断点（源端）→ 输入名称（如"24V+"）
  2. 在目标页插入中断点（目标端）→ 输入相同名称
  3. EPLAN 自动标注交叉引用（页码+位置）
  4. 用连接导航器检查所有中断点是否正确配对
  5. 调整中断点排序：导航器中拖拽
提示：中断点命名建议用功能名（如"24V+""0V""L1"）而非数字编号。这样修改页码顺序后不需要重新关联。跨页连接的目标页码标注是自动更新的。
配套 8

第一个项目：电机启停原理图

新建项目、选模板、新建页、插入主电路与控制电路符号、连线、生成端子排与 BOM，导出 PDF。

核心概念

本主题将前 7 个主题串联为一个完整项目：三相电机启停控制。包含：主电路（断路器→接触器→热继电器→电机）、控制电路（急停+点动+自锁+过载指示）。这是 EPLAN 入门的"Hello World"。

关键操作步骤

  1. 新建项目 → 选 GB 模板 → 新建多线原理图页
  2. 主电路：插入 3P 断路器(-QF1) → 接触器主触点(-KM) → 热继电器(-FR) → 三相电机(-M)
  3. 控制电路：插入急停(-SB1) → 点动按钮(-SB2) → 自锁按钮(-SB3) → 接触器线圈(-KM) → 热继电器常闭触点
  4. 用连接定义点标记电位：L1/L2/L3（主电路）、控制电源+/-
  5. 放置中断点连接主电路与控制电路的跨页
  6. 生成报表：BOM 部件清单 + 端子排图表
  7. 导出 PDF 汇总
常见错误：自锁回路接触器辅助触点与点动按钮并联时方向接反——导致按点动时电机不停。正确的自锁：辅助常开触点并联在自锁按钮两端（不是点动按钮两端）。
